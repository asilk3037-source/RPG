# RPG

Catálogo de compras de Chamado de Cthulhu (7ª edição), em português.

Abra `index.html` no navegador para consultar itens, preços, efeitos e referências dos livros. O catálogo funciona offline e inclui busca, filtros e o botão **Ver munições**, com tipos, danos e preços disponíveis para cada arma.

Os preços são os originais dos livros, em dólares. Informações não especificadas nas fontes estão sinalizadas. Os PDFs dos livros não estão incluídos neste repositório.
